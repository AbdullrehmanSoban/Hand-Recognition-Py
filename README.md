Hand Gesture Recognition System (Python)
A real-time computer vision application that detects and classifies hand gestures using OpenCV and cvzone's HandTrackingModule. The system captures live webcam feed, tracks finger positions, and recognizes four distinct gestures — Open Palm, Fist, Thumbs Up, and Victory Sign — with a color-coded visual overlay showing the detected gesture and hand count. Supports simultaneous detection of up to two hands.
